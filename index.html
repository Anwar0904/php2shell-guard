How the assessment works

The version checker compares stable version numbers with the first fixed upstream release for a supported branch. Vendor packages may backport fixes without changing the PHP version number, so package status must be confirmed with its vendor.

The optional website check reads headers only for explicitly allowlisted HTTPS hosts. The local diagnostic reports PHP CLI information and its JSON report is assessed in this browser, not uploaded. CLI PHP may differ from the runtime used by a web server.

These checks provide limited evidence. They do not verify the web-serving runtime, confirm vendor backports, or prove that a system is secure or vulnerable.
